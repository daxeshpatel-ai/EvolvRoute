# Contributing to EvolvRoute

Thanks for your interest in EvolvRoute. This is a small, focused project — contributions
that keep it lean and portable are welcome.

## Ways to contribute

- **Add a worker lane** — point the router at a new CLI or model (the most common
  contribution; see below).
- **Sharpen the scoring policy or break-even heuristic** — improve how the router decides
  what's cheapest-capable.
- **Stress-test the self-learning loop** — throw new task types at it and report where
  routing breaks down.
- **Improve the docs** — clearer onboarding gets the next person to their first route faster.
- **File focused bug reports and feature requests** — use the issue templates.

New here? The [`good first issue`](https://github.com/daxeshpatel-ai/EvolvRoute/labels/good%20first%20issue)-labeled
issues are the easiest entry point, and [`help wanted`](https://github.com/daxeshpatel-ai/EvolvRoute/labels/help%20wanted)
marks where an extra hand goes furthest.

## Adding a worker lane

Most contributions are new lanes (a CLI the router can dispatch to). A lane is additive:
a capability card plus four small touch-points, no engine changes. The full walkthrough is
in [`docs/ADDING_A_LANE.md`](docs/ADDING_A_LANE.md) — read it before opening a lane PR.

## How the learning loop expects verdicts

The router only learns from outcomes. After a delegated artifact is integrated, an outcome
must be recorded:

- **Automatic** — a timeout, error, or empty output is recorded as a negative verdict with
  no human input.
- **Manual** — `./delegate.sh verdict <id> accept|edit|reject [edit_pct]` captures human
  judgment (`accept` = used as-is, `edit` = used after edits, `reject` = discarded).

Verdicts feed `ingest.py sync` (re-embed + recompute centroids) and `digest.py` (stop-cells).
If you add a lane, make sure its ledger rows map back to your handler id so verdicts attribute
correctly — otherwise the loop can't learn your lane.

## Before you open a PR

Run these and make sure they pass:

```bash
bash -n delegate.sh                 # the entrypoint still parses
python3 -m py_compile router/*.py   # router modules compile
python3 -m py_compile digest.py     # digest compiles
```

## Code style

- **Python: stdlib-only.** The router runs with no third-party imports beyond the
  embedder (`model2vec`). Don't add dependencies; if you think you need one, open an issue
  first.
- **Bash: portable.** Target POSIX-ish `bash` that works on stock macOS (no `timeout`
  binary — use the existing watchdog) and Linux. No GNU-only flags.

## Operational data is gitignored

`ledger.jsonl`, `usage.log`, `DIGEST.md`, `router/orchestra.db`, and `router/stopcells.json`
are live operational data regenerated by the learning loop and are **never committed**. Work
from the tracked `.example` seeds instead:

```bash
cp ledger.jsonl.example ledger.jsonl
cp usage.log.example usage.log
```

Never put secrets in delegation prompts — they reach the worker CLI and its session store.

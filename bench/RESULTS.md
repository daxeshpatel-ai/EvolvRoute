## TL;DR

**Quality-held-constant strategies** — every one of these keeps high-tier work (architecture / review / planning / security-critical) on the frontier; they differ only in what they do with the rest:

| Strategy | Total notional cost | EvolvRoute savings |
|---|---|---|
| **EvolvRoute (routed)** | **$1.6455** | — |
| All-frontier inline (no router) | $4.1846 | **60.7%** |
| All-fusion (run every lane, pick best) | $5.7415 | **71.3%** |

Across 28 tasks, routing to the cheapest-capable lane costs **$1.6455** vs **$4.1846** to run everything on a frontier model inline — a **60.7% reduction** — and **71.3%** less than fusing every lane in parallel, all while keeping every high-tier task on the frontier (see governance below).

### What about "just use one strong model for everything"?

Forcing GPT-5.5 on *every* task (including architecture, review, and security-critical work) totals **$0.6334** — cheaper than EvolvRoute's **$1.6455**, but only by **downgrading the high-tier tasks EvolvRoute deliberately keeps on the frontier**. It is not a quality-equivalent baseline. The fair, apples-to-apples question is: *on the work the router actually delegated, did it pick cheaper lanes than blindly using the flagship?*

| On the 15 delegated tasks | Notional cost |
|---|---|
| **EvolvRoute lane selection** | **$0.2235** |
| Force GPT-5.5 (flagship) on the same tasks | $0.3475 |

On the delegated subset the router is **35.7% cheaper** than forcing the flagship — it picks `mini`/`flash`/relay where they suffice and only spends up when the task warrants it.

## Method & honesty notes

- **Real engine.** Each row is a live `route.py … --json` call; this benchmark does not reimplement routing.
- **Project's own prices.** Rates are the metered-equivalent reference table in `MODEL_REGISTRY.md` (NOT real billing — workers bill flat subscriptions). `out_tokens = out_chars/4`, matching `delegate.sh`.
- **`claude_keep` is priced, not free.** Kept work is charged at the opus-class frontier rate, so the router gets no free lunch on the tasks it (correctly) refuses to delegate.
- **Routing isolated from break-even.** The cost/quality run sets `MIN_DELEGATE_TOKENS=0`; the floor is verified separately at defaults in the governance check, so the two effects don't double-count.
- **Relay cost** assumes agy compresses context to ~30% before the codex stage — a documented, conservative modeling choice.
- **Media is cost-neutral** (flat per-call in every strategy), so the savings come entirely from text/code/doc/research routing.
